# Stanford University ML DL LLM CheatSheet

A comprehensive collection of cheat sheets and reference materials from Stanford University covering Machine Learning, Deep Learning, and Large Language Models.

## Contents

- **Time Series Models**
- **Convolutional Neural Networks**
- **Deep Learning** (Tips & Tricks, Super Cheat Sheet)
- **Machine Learning** (Tips & Tricks, Super Cheat Sheet)
- **Recurrent Neural Networks**
- **Transformers & Large Language Models**
- **Supervised & Unsupervised Learning**
- **Refresher materials on Algebra, Calculus, Probabilities, and Statistics**
- And more!
